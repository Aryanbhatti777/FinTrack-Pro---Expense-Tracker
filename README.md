# FinTrack Pro

A personal finance tracking web application to manage your income and expenses.

## Features

- User registration and login
- Add, edit, and delete transactions
- Categorize transactions (Food, Shopping, Bills, etc.)
- Dashboard with financial overview
- Cash flow chart visualization
- Search and filter transactions
- Dark mode toggle
- Multiple currency support
- Profile settings management

## How to Use

1. Open `register.html` to create a new account
2. Login with your credentials
3. Add your income and expense transactions
4. View your financial dashboard with charts and summary
5. Manage your profile and preferences in settings

## Tech Stack

- HTML
- CSS
- JavaScript
- Chart.js
- Font Awesome
- Google Fonts (Inter)

## Pages

- **Register** - Create a new account
- **Login** - Sign in to your account
- **Dashboard** - View transactions and financial overview
- **Settings** - Update profile and preferences

## Getting Started

Open `register.html` in your browser to start using the application.
